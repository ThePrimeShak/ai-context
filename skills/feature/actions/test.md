# Test the feature

1. Identify the active spec and work branch. Read the spec's verification cases, referenced rules from `context/project-overview.md`, and test commands in `context/coding-standards.md`.
2. Run existing checks for the affected behavior. Add or update tests when required by the spec or standards, or when existing coverage would miss a specific regression. Cover relevant success, boundary, and failure cases.
3. Use the configured test environments. For manual checks, record the steps and observed outcome. Mark goals verified only when there is evidence for them.
4. Report the commands, results, and anything that still needs verification.
